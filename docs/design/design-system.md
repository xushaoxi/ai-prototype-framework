# 界面基线

组件与页面的使用条件见 [业务原型设计指南](design-guidelines.md)。该指南区分待确认建议与已落地规则；本文件记录当前视觉基线。

概念由内置 Image Gen 生成，参考 docs/design/ledger-concept.png。用途为 T01 标准台账完整桌面，不是运行时背景或静态页面替代。实现使用真实 Ant Design 组件。

色彩：背景 #f5f7fa（冷灰）、表面 #ffffff、正文 #172b34、次要 #526470、辅助 #63727d、边线 #dfe5eb、浅边线 #e8edf1、强调 #0f766e。系统中文无衬线；标题28、正文14、密集表格12、辅助11；主面板圆角10，控件8。桌面白色固定侧栏220、顶栏64、内容边距32；默认台账以日常查找与处理记录为主，不展示重复统计卡片，状态标签承载计数；主列表单面板。手机390宽侧栏折叠为Drawer，查询控件自动换行、表格局部横滚。无装饰性照片/插画/渐变。

必要扩展状态：创建编辑使用620px Modal（手机自适应），详情560px Drawer，设置440px Drawer，使用指南同色系纵向章节。所有按钮需要真实交互。支持加载/空态/失败重试/只读；详情活动记录、状态操作确认。

首屏允许文案以概念为准：原型工作台、业务原型框架、资产台账、供应商台账、使用指南、工作空间、演示设置、资产说明、新增资产、状态标签计数、查询控件、真实记录、分页、本地数据说明。新增必要说明：统计和CSV导出范围（避免用户误解过滤语义）。图标使用 Ant Design 线性图标，与组件默认保持一致。

2026-10-26：按已确认的 PAGE-001/LIST-001 更新，原概念图中的统计横排不再作为默认台账要求；其余视觉决策保持现有基线。

QUERY-001：标准台账关键词与类别通过点击「查询」或关键词框 Enter 统一提交，查询区提供可见的回车提示；状态标签即时切换已生效条件。

QUERY-002：条件与查询按钮分组，按列表内容区宽度排布，宽屏最多3个、窄屏最多2个、手机1个；关键词与类别全部展示。资产折叠入口按 QUERY-003 实现。

QUERY-003：资产启用日期范围与状态下拉。宽屏前三个条件直接展示，状态折叠；窄屏日期也移入更多筛选。日期按天含边界，状态标签和下拉联动，隐藏已生效条件显示数量。

NAV-001/PAGE-002：顶部功能标签替代浅层面包屑，保留多页面查询与滚动现场；标准台账隐藏重复大标题说明，对照指南进入顶栏，新增与导出刷新位于查询区下方的列表操作栏。功能页标签与状态筛选分层。

COL-001/002：列表操作栏的导出右侧放置仅图标的列设置；数据列表头提供列宽手柄，80–600px，名称和操作保留。显示与宽度按模块在浏览器保存。导出先独立选列，默认当前显示列，支持补选隐藏数据列。

COL-003：当列表容器宽于列总宽时，优先把剩余空间分给未手动调整的列，使表格铺满内容区；用户调整过的列保持设置的宽度。空间不足时保留列宽并在表格内横向滚动。表头只显示一套可拖动分隔线。

COL-004：列设置行提供拖动、上/下箭头及左/右固定；固定分区内排序，窄屏或空间不足暂不固定并提示。列顺序和固定方式按模块保存，导出跟随当前顺序。

## V1 补充使用约束（2026-10-29）

规则来源与采用范围见研究清单第六节；本地视觉值为项目选择，不是外部体系统一尺寸。

- 新增页面以正文14px和清晰分组为起点，现有11/12px密集文本需结合缩放/对比度复核，不能扩散为所有页面默认字号。新增布局以4px步长，常用8/16/24/32px；相关元素靠近，分组留白更大。
- 语义色必须配文字；金额右对齐并写清币种/单位。白色表面与冷灰背景延续现有层级；避免套娃卡片、装饰渐变和重复标题。
- 按钮/表单尺寸沿用现有Ant Design主题，图标保持线性风格。自定义间距、颜色、层级优先复用主题和现有CSS变量；V1尚未声明所有硬编码已收敛为tokens。
- 响应式按可用内容宽度调整，不能仅按设备名称硬套布局；表格保留自身横滚，详情/编辑在手机不超视口。自定义动画支持减少动态效果偏好，暗色主题不在当前实现范围。
- 字段错误/只读/加载/失败/未保存状态按 FORM-007/008、FEEDBACK-001处理；通用组件示例与三种表单容器是规则的交互落点，待本轮整体验证。
- ACCESS-001列出的对比度、键盘、焦点、缩放、目标尺寸与读屏是验收目标；当前色值和组件默认样式不能作为WCAG全面合规证明。

2026-10-30：主题唯一来源为src/core/theme.ts，同时生成Ant配置与CSS变量。正文14、控件36、公共圆角8/10、侧栏220与顶栏64及间距尺度均在该入口维护；本文件解释语义，数值以入口为准。原本近似但不一致的次要文字与边线值已按语义合并。
