# 界面基线

概念由内置 Image Gen 生成，参考 docs/design/ledger-concept.png。用途为 T01 标准台账完整桌面，不是运行时背景或静态页面替代。实现使用真实 Ant Design 组件。

色彩：背景 #f5f7fa（冷灰）、表面 #ffffff、正文 #172b34、次要 #84919e、边线 #e8edf1、强调 #0f766e。系统中文无衬线；标题28、正文14、密集表格12、辅助11；主面板圆角10，控件8。桌面白色固定侧栏220、顶栏64、内容边距32；状态统计横排单容器；主列表单面板。手机390宽侧栏折叠为Drawer，查询控件自动换行、表格局部横滚。无装饰性照片/插画/渐变。

必要扩展状态：创建编辑使用620px Modal（手机自适应），详情560px Drawer，设置440px Drawer，使用指南同色系纵向章节。所有按钮需要真实交互。支持加载/空态/失败重试/只读；详情活动记录、状态操作确认。

首屏允许文案以概念为准：原型工作台、业务原型框架、资产台账、供应商台账、使用指南、工作空间、演示设置、资产说明、新增资产、四项业务统计、查询控件、真实记录、分页、本地数据说明。新增必要说明：统计和CSV导出范围（避免用户误解过滤语义）。图标使用 Ant Design 线性图标，与组件默认保持一致。
