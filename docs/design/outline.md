# 业务原型设计指南大纲

版本：V1 基础指南；更新日期：2026-10-30。

目标：提供可复用工作台的基础决策、示例与验收方法。16章均映射实用规则；完整决策覆盖不表示批量、草稿、复杂图表等均已实现。本轮在用户批量授权下自主适配，不再逐条等待确认。

配套资料：[来源研究与适配清单](design-guidelines-research.md)、[设计规则正文](design-guidelines.md)、[当前界面基线](design-system.md)。参考来源的具体链接与阅读范围以研究清单为准。下文来源是后续对照入口，不表示已对每个子题完成研究。

## 01 适用范围与设计原则

- 目标用户、角色、使用频率和核心任务。
- 原型验证、业务演示与正式生产系统的区别。
- 效率、易学、信息密度与一致性的取舍。
- 默认规则、业务例外与扩展边界。
- 原型仿真说明与数据可信度。

参考：Ant Design、TDesign、Arco、Fluent。
V1 基础规则：PRINCIPLE-001（详见正文，检查方法不代表已通过）。
工作台对应：PAGE-001 已确认并落地，默认 T01 用于日常查找和处理记录；其他原则见 PRINCIPLE-001。

## 02 信息架构与导航

- 系统、工作空间、业务模块、页面的层级。
- 侧栏、顶部导航、面包屑、标签页的使用条件。
- 模块导航、视图切换与状态筛选的区别。
- 导航命名、当前位置、返回与深链接。
- 返回列表时的查询、页码和滚动位置。
- 导航收起、小屏菜单和扩展模块。

参考：Honeycomb、Ant Design、TDesign。
V1 基础规则：LAYOUT-001、FORM-008（详见正文，检查方法不代表已通过）。
工作台对应：NAV-002按规范与基础、页面结构、组合与反馈组织入口，旧业务地址保留在兼容区；NAV-001 已落地，侧栏打开唯一功能标签，保留页面查询与滚动现场，支持关闭和键盘切换。

## 03 页面类型与布局

- 列表页、表单页、详情页、工作台、分析页的选择。
- 页面标题、说明、主操作、内容区和辅助区。
- 信息优先级与首屏空间。
- 单栏、分组、主从、树表、卡片、分步布局的适用条件。
- 页面级、区域级与行级操作的归属。
- 标准容器与特殊业务扩展。

参考：Honeycomb 典型案例与模板、Ant Design。
V1 基础规则：LAYOUT-001（详见正文，检查方法不代表已通过）。
工作台对应：PAGE-002/PAGE-003 已落地；资产台账已确认为标准查询表格 V1，后续搜索查询表格以此为基准并按业务适配。台账取消重复标题说明，对照指南位于顶栏，查询与列表操作分区。

## 04 视觉基础

- 品牌色、语义色、文字色、背景色、边线与对比度。
- 字体、字号、字重、行高和数字排版。
- 间距、网格、对齐、宽度、断点与页面边距。
- 组件尺寸与舒适、紧凑密度。
- 圆角、阴影、层级、遮罩和固定区域。
- 图标、插画、图表配色与装饰使用条件。
- 动效时长、用途和减少动态效果。
- 设计 tokens 与主题；暗色模式按需评估。

参考：Ant Design、TDesign、Arco、Atlassian。
V1 基础规则：VISUAL-001（详见正文，检查方法不代表已通过）。
工作台对应：THEME-001已接入统一Ant/CSS主题来源，具体覆盖与未验证状态见规则正文。

## 05 通用组件使用

- 按钮主次、文字链接、图标按钮、禁用与加载。
- 单选、多选、下拉、开关、日期与数字输入的选择。
- 标签、徽标、状态与计数的区别。
- 标签页、折叠面板、卡片和分组容器。
- Tooltip、帮助文字、气泡确认与消息组件。
- 组件组合、文案、尺寸及必要状态。

参考：Ant Design、TDesign、Arco、Honeycomb 基础规范。
V1 基础规则：COMPONENT-001（详见正文，检查方法不代表已通过）。
工作台对应：统一现有组件使用；不另造一套基础组件库。

## 06 查询与筛选

- 关键词搜索范围、匹配方式与提示。
- 即时查询、回车查询与按钮查询的选择。
- 常用条件、组合条件、高级筛选与展开收起。
- 单选、多选、范围、日期及条件之间的关系。
- 默认条件、已生效条件、清除和重置。
- 状态标签与筛选项重复的处理。
- 查询、排序、分页、统计与导出的数据范围。
- 慢响应、连续输入与结果更新时的反馈。
- 保存查询与自定义视图：按需扩展。

参考：Honeycomb 表格页、Carbon Filtering/Search、Ant Design。
V1 基础规则：QUERY-001/002/003/004（详见正文，检查方法不代表已通过）。
工作台对应：QUERY-001/002/003/004 已落地，统一点击/Enter查询、响应式条件排布、资产日期范围与状态更多筛选、隐藏条件数量和状态标签联动，并区分已生效条件与待提交修改，支持逐项清除和无结果恢复。

## 07 列表与表格

- 表格、卡片列表、树表、展开行的选择。
- 列的优先级、顺序、宽度、对齐与固定列。
- 长文本、换行、截断与完整内容查看。
- 排序、分页、页大小与结果总数。
- 行密度、斑马纹、分隔、悬停与选中。
- 行操作、更多菜单、批量操作及跨页选择范围。
- 行点击、名称链接、详情入口与可发现性。
- 行内编辑和整表编辑的适用边界。
- 列设置、大数据量与性能反馈：按需扩展。

参考：Carbon Data Table、Honeycomb 表格页与列表模板、Ant Design。
V1 基础规则：TABLE-001（详见正文，检查方法不代表已通过）。
工作台对应：PAGE-002/COL-001/COL-004/LIST-002 已落地，列表操作栏左侧新增、右侧导出/列设置/刷新，支持显示列、列宽、列顺序和固定偏好；保留分页与行操作，横向溢出时提示查看其他列，截断文本可访问全文。

## 08 数字指标与可视化

- 何时需要统计数字、提醒、卡片或独立分析页。
- 总数、状态计数、待办数、异常数的区别。
- 与标签、分页重复的信息如何合并。
- 指标范围、时间、单位、更新时点及计算口径。
- 点击指标后的筛选或跳转。
- 趋势、对比、目标与图表类型选择。
- 加载、无值、错误与过期数据。

参考：Honeycomb 数据指标、Ant Design 数据展示；复杂图表另行研究。
V1 基础规则：METRIC-001（详见正文，检查方法不代表已通过）。
工作台对应：LIST-001 已确认并落地，默认移除重复统计区，保留状态标签计数；可视化基础选择见 METRIC-001，复杂图表不在V1实现范围。

## 09 表单与编辑

- 新增、编辑、复制与查看的区别。
- 单列、多列、分组、分步与关联字段。
- 标签、必填、可选、默认值与帮助提示。
- 字段类型、输入格式、范围、精度和联动。
- 校验时机、字段错误、整体错误与错误定位。
- 保存、取消、重置、重复提交与保存反馈。
- 未保存退出、草稿、恢复与并发冲突。
- 长表单、明细子表、导入录入：按需扩展。

参考：Ant Design 表单页、Honeycomb 数据录入、GOV.UK 表单相关模式。
V1 基础规则：EDIT-001、FORM-008（详见正文，检查方法不代表已通过）。
工作台对应：FORM-001 规定容器选择，FORM-004 规定完整页面三列，FORM-005 统一必填标识；FORM-006 在新增资产及三种容器中展示通用字段控件、格式和默认值规则。FORM-007统一首次提交校验、错误计数与定位、已报错字段复查、失败保留输入和保存锁；未保存退出保护见 FORM-008，待本轮整体验证。

## 10 详情与业务状态

- 信息摘要、字段分组与关键数据层级。
- 当前状态、可执行动作和不可操作原因。
- 状态流转、确认、完成与失败反馈。
- 活动记录、时间线、修改人与时间。
- 关联数据、附件和明细：按需扩展。
- 状态名与业务动作名的一致性。

参考：Honeycomb 详情页与关键路径、Ant Design。
V1 基础规则：DETAIL-001（详见正文，检查方法不代表已通过）。
工作台对应：详情抽屉、活动记录与模块状态机。

## 11 弹层与任务容器

- 独立页面、Modal、Drawer、Popover 的选择。
- 按任务时长、复杂度及上下文依赖决定容器。
- 标题、尺寸、滚动、底部操作和关闭入口。
- 焦点进入、键盘操作、退出与焦点归还。
- 未保存关闭、遮罩点击与 Esc 的行为。
- 多层弹窗、抽屉内操作与移动端适配。

参考：Ant Design、Carbon Dialogs、TDesign；具体规则需逐项核实。

## 12 系统反馈与异常恢复

- 首次加载、局部刷新、骨架屏、进度与长等待。
- 初始无数据、筛选无结果和任务完成后的空态。
- 成功、提示、警告、失败的级别和载体。
- 网络失败、校验失败、存储失败和版本冲突。
- 重试、保留输入、部分失败与恢复操作。
- 只读、禁用、不可见和无权限的语义区别。
- 仿真权限与正式授权的边界标识。

参考：Carbon Empty States/Loading/Notifications、Atlassian 消息、Honeycomb 反馈。
V1 基础规则：FEEDBACK-001（详见正文，检查方法不代表已通过）。
工作台对应：演示场景、API 错误、存储异常与只读模式。

## 13 危险操作与数据工具

- 删除、归档、停用、重置等操作的风险分级。
- 何时需要确认、撤销或再次核对。
- 确认内容、受影响对象、数量及不可恢复后果。
- 批量操作与部分成功：能力具备后再定义。
- CSV 导出范围、字段、格式及结果反馈。
- 备份、导入、校验、覆盖与恢复。
- 模拟数据、个人数据与演示安全边界。

参考：Honeycomb、Ant Design、GOV.UK；本项目数据工具约束。

## 14 文案与数据格式

- 业务术语、导航、标题、字段、状态和动作命名。
- 按钮用语、提示、确认、成功与错误消息。
- 金额、数字、百分比、单位和精度。
- 日期、时间、时区与相对时间。
- 0、空值、未知、未填写和不可用。
- 中文标点、中英文混排、缩写与长内容。
- 本地化预留；多语言运行时按需求评估。

参考：Honeycomb 文案/数据格式、Ant Design Data Format、Atlassian Content。
V1 基础规则：CONTENT-001（详见正文，检查方法不代表已通过）。
工作台对应：所有页面、表格、活动记录及导出。

## 15 响应式与可访问性

- 桌面、窄屏、手机的任务优先级与布局变化。
- 表格局部横滚、列优先级和触控操作。
- 文字缩放、重排与固定区域遮挡。
- 键盘顺序、可见焦点、弹层焦点与快捷操作。
- 标签、语义结构、读屏及动态状态通知。
- 色彩对比、非颜色提示、点击区域和减少动效。
- WCAG 2.2 AA 目标、适用条件和验证方法。

参考：W3C WCAG、Fluent、国内各体系可访问性资料。

## 每条规则的统一格式

1. 规则 ID 与标题。
2. 要解决的用户任务和问题。
3. 参考来源：原文链接、核实日期、原文建议与本地推论。
4. 默认做法、使用条件、不适用场景和例外。
5. 正反例：优先使用工作台里的真实场景。
6. 状态要求：正常、加载、空、失败、只读及适用的异常。
7. 小屏与可访问性检查。
8. 工作台落点、关联业务需求及验收方法。
9. 决策状态、实现状态与验证证据，分别记录。

决策状态：待研究 → 待讨论 → 已确认 → 已废弃。
实现状态：未实现 / 部分实现 / 已实现 / 不适用。
验证状态：未验证 / 验证失败 / 已验证（注明范围与证据）。
