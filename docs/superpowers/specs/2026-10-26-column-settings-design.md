# 列宽、显示列与导出选列

用户请求三项能力：拖动调整列宽、选择显示列、导出时选择列。采用现有共享台账，不复制页面。

默认方案：列设置在列表操作栏；按模块本地记住显示列及宽度，可恢复默认。名称与操作列保留，其余列表数据列（包括状态）可隐藏。列宽80–600px，拖动与键盘左右键（10px）调整，Home/End到上下限。操作列宽固定，避免操作挤压。

导出采用选择弹窗，默认当前显示的数据列，允许选择当前隐藏数据列，至少一列；不包含操作列及非列表字段。导出列选择与显示设置独立，取消不修改表格。仍导出已提交查询的全部页，沿用CSV安全转义。候选字段由模块inTable及状态派生，不扩大到个人内部数据字段。

备选方案为导出始终跟随显示列，虽少一步却不能单独选择；本次用户明确要求选列，因此采用独立确认。只记录浏览器本地偏好，不接真实服务。

失效或损坏本地偏好回退默认；忽略已删除列，新列按默认加入，保留名称。存储不可写时本次会话可用并提示无法持久保存。手机所有选定列可通过表格横滚查看，列设置仍可用；不再自动隐藏用户选中的编号列。
