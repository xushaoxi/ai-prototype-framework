# 工作台内设计指南：已确认方案

## 目标

将现有 16 章大纲接入工作台，方便阅读规范并对照真实界面。保留使用指南的启动、开发和交付职责；设计指南单独承载设计决策。

## 方案比较

1. 独立指南页：适合完整阅读，但与台账来回切换时不便对照。
2. 独立指南页加台账侧边参考面板（推荐）：完整阅读与同屏对照兼顾；小屏采用抽屉阅读，再关闭查看台账。
3. 全量组件展厅：可系统查看状态，但需要建设和维护额外示例；目前先以真实台账为例，后续规则需要时再补示例。

用户于 2026-10-26 确认方案 2。

## 推荐方案细节

- 侧栏新增“设计指南”，支持独立 hash 路由、刷新和直接访问。
- 指南页呈现 16 章目录、章节议题、参考资料和规则成熟度。未展开内容明确标记待完善，不伪造完整规范。
- 已有 LIST-001 以“候选建议”展示；确认状态与实现状态分开，当前统计区仍在。
- 台账提供“对照指南”入口；桌面面板不遮挡表格，保留列表操作与滚动；面板可关闭。空间不足时切换抽屉，避免强行压缩内容。
- 首期只展示真实工作台作为示例，不额外建设组件展厅。
- 复用项目现有文档内容作为来源，避免手写第二份 16 章内容造成漂移；实现时选择最小解析或结构化生成方案，不新增 Markdown 渲染依赖，外部链接安全打开。
- 沿用现有 Ant Design 与视觉基础，不引入新 UI 体系，不改变 Mock、业务状态、数据或权限规则。

## 验收

- 导航、标题、直接访问、章节切换与参考链接正常。
- 16 章内容与文档对应，候选建议及未展开章节状态准确。
- 桌面可同时看到规则与实际台账，查询、详情和编辑仍可操作。
- 手机可打开、阅读与关闭指南，无页面整体横向溢出。
- 对应需求与测试同步；运行 verify、test:e2e，检查桌面/移动截图与控制台；交付执行 deliver，以实际日志为证。

## 决策

采用方案 2：独立指南页 + 桌面侧边参考面板，小屏抽屉。后续新增组件展厅另行评估。
