# QUERY-001 显式查询与回车快捷操作

用户已选择点击查询，并要求增加回车查询。将“回车”理解为关键词输入框的 Enter 键，无需新增重复按钮。

## 决策

- 关键词和类别为待提交条件，点击查询或关键词框按 Enter 统一应用，回到第一页，两种操作调用同一查询逻辑。
- 状态标签立即切换，但只使用已生效条件；重置立即清空条件并恢复全部。
- 在关键词框提供“按 Enter 查询”提示，不改变现有搜索范围说明。
- 中文输入法确认候选词的 Enter 不提交；结束选词后普通 Enter 才查询。
- 第06章接入 QUERY-001，记录规则、参考依据与验收；资产与供应商同步规范。

## 范围与验证

不增加通用表单引擎，不改变API或store。保留已存在的 onPressEnter 逻辑，沿用组件自带输入法保护，只补提示与验收。浏览器覆盖点击/回车等价、组合条件、待提交条件不自动应用、回到第一页、状态使用已应用条件、重置、输入法选词和移动端。测试监听真实HTTP，不重复拦截MSW。运行完整deliver并查看截图。
