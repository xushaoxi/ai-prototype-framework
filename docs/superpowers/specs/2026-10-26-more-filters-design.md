# 资产台账更多筛选

用户已确认：关键词、类别、登记日期范围常用展示，状态在更多筛选中；窄内容区日期也进入更多筛选。日期精确到天、包含起止当天。状态下拉框与标签共用一个生效条件，点击标签即时应用并覆盖状态草稿；提交下拉框同步标签。所有其他草稿保留且不会因切换标签自动提交。

方案沿用已选择的内联展开，避免额外抽屉。状态标签保留便捷切换，状态下拉仅作为组合查询入口，不产生第二套状态条件。

模块定义使用有限的queryFilters扩展声明dateRange/status；仅资产启用。日期过滤在store校验、执行，计数遵守除状态外的所有已提交条件；导出沿用相同查询。允许单边日期范围，格式非法或起止倒置拒绝。

列表宽度至少1000px直接展示日期，否则日期随状态进入折叠区。更多筛选入口仅在收起时显示已生效隐藏条件数，日期起止合计一个，状态一个；不计草稿。收起不清空，重置清空全部条件、默认排序与第一页，保留展开选择。展开区有可见字段标签并支持键盘访问。

不复制台账，不增加真实服务或通用筛选配置引擎；供应商不启用新增UI。完成指南、规范、核心/HTTP及浏览器验证后本地deliver，不推送部署。
