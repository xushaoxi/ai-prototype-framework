# 列排序与固定

用户要求在列设置中增加拖拽排序、列名后的上下箭头和固定列。沿用当前模块独立浏览器偏好，支持固定左侧、右侧及不固定；操作列依旧默认固定右侧且不参与配置。

## 行为

列设置按实际展示顺序列出全部可配置数据列（含隐藏列）；每行有拖动手柄、复选框、上下箭头和固定方式按钮。固定列按左固定、普通列、右固定分区；拖拽和上下箭头在同一分区调整顺序，跨区通过更改固定方式完成。入口解释此规则；移动首尾按钮禁用，拖拽必须可被箭头操作替代。

设置固定方式时按已有顺序稳定分组，放在对应区域末尾。切换显示、顺序、固定、列宽互不重置，按模块保存；恢复默认清除全部设置。旧版偏好中的显示和宽度保留，新增排序默认为模块定义顺序，新增固定默认为无。损坏和无效键安全归一化。

显示表格以分组后的顺序构建；桌面固定左/右，在窄屏或固定列总宽会挤占中间少于160px时暂时取消固定（含操作列），保留已设的顺序与标记，并提示空间不足。空间恢复后自动应用。导出弹窗默认当前可见列，并按当前列顺序列出，可单独选择隐藏列；不包含操作列，保持查询范围与CSV安全。
