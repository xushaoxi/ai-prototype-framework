# 查询与表格易读性优化

用户任务是日常查找、浏览和处理台账记录。保留显式查询与当前模块规则，让用户能辨认上次已应用的筛选、发现横向溢出的列、读完整长名称，并在无结果时恢复查询。

目标：应用条件始终可见且可单独清除；状态标签与状态下拉仍表示同一个已应用状态；有未提交更改时明确提示；有真实横向溢出时显示滚动提示；筛选无结果时提供清条件入口；长名称可通过指针或键盘查看；查询布局在展开更多筛选时仍稳定。

非目标：新增业务状态、批量处理、服务端查询方案或保存搜索。批量处理需要原子业务规则，保存查询需要命名、范围和持久化约定，均不从单纯列表优化推定。

约束：复用 LedgerPage、Ant Design 与现有 API/MSW；数据仍由 store 提供；无新依赖；保持桌面和手机无页面级横向溢出。

实现选择：通过独立筛选摘要、结果空态按钮、真实溢出检测与单元格 Tooltip 改善现有界面；不将筛选改为即时请求，也不增加固定占高区域。窄屏提示只在表格实际有隐藏列时出现。
