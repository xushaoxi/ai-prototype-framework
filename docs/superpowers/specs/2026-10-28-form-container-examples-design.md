# 表单容器示例设计

目标：从设计指南第 09、11 章进入一个示例功能页，使用同一套资产字段和示例记录，比较弹窗、右侧抽屉及完整页面的新增、编辑体验。完整页面通过独立地址进入，并可返回示例页。

方案：一个示例页提供容器选择、适用规则和一条示例资产；新增或编辑依据所选容器打开相同字段。示例复用资产模块字段、控件与必填规则，提交只作演示，不写入真实台账。新建和编辑的示例输入与结果不作为业务数据保存。

范围：不增加三个主菜单，不改变资产台账现有容器；表单容器的选择仍按 FORM-001 逐个业务判断。抽屉以页面上下文为参考，不能宣称遮罩下的页面可操作。完整页面采用工作台路由及标签页，可直接访问和返回。

边界：工作台多标签页中非活动页面不显示示例弹层；抽屉与完整页面在手机视口可用，示例提交显式提示不写入台账；不添加依赖、不新增后端接口。
