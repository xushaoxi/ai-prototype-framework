# 后台通用原型模式库 V2

用户要求常见后台系统可直接采用完整基础库，且已授权自主整批执行。本轮采用现有React/Ant Design和T01基线，不新造低代码引擎，不提供真实认证、权限或工作流服务器。

交付为可操作模板、类型化复用接口、共享仿真API、覆盖清单及新项目接入说明。模板包括：高级表格/树表/卡片/主从；分组/分步/联动/明细/附件/草稿表单；组织树/用户角色/权限；审批/待办/消息/审计；仪表盘/设置/登录仿真/结果；CSV导入映射校验、文件中心和回收站。现有T01继续作为标准查询容器，不改变既有规则。

新增模式仿真域与T01记录域显式隔离，业务数据统一由src/mocks/store.ts管理，经core/api.ts的patternApi和MSW。模式数据独立命名空间，可重置/备份恢复并清楚标明，不混称T01备份。版本校验、批量原子性、父子循环、非法审批/权限/附件元数据均由store拒绝。附件只存元数据，不上传文件内容；登录不保存密码。示例必须显示仿真标记。

常见模式有正常、加载、空、失败、只读及适用异常。涉及数据更改必须真实更新仿真域并支持重新读取，不用成功toast替代实现。控件与模板通过类型化props/API复用，不复制业务整页。

完成：覆盖目录无假完成项、入口可达、实际交互和持久恢复；规范、类型、领域/HTTP/浏览器测试、桌面手机截图与控制台及完整deliver。具体生产业务仍需接入后端和业务规则；不宣称覆盖无限未来业务。
