# 详情异常恢复 V1

DETAIL-001：共享 RecordDetail 保留列表已知摘要，并明确提示最新详情加载中或失败；摘要可能不是最新数据。详情 HTTP 与活动记录 HTTP 独立完成、独立显示失败，分别提供重试按钮；一方失败不丢弃另一方成功结果。重试期间该区域显示加载反馈，详情摘要仍可阅读。

DETAIL-002：打开记录和关闭抽屉递增请求代号；重试沿用当前打开记录代号。旧请求在关闭或改看其他记录后不得更新摘要、活动记录、错误和加载状态。继续通过 api/MSW/store 获取真实演示数据，不增加业务权限或新字段类型；字段仍使用模块定义与 displayFieldValue。

验收：tests/e2e/detail-feedback.spec.ts 覆盖双失败分别重试、已知摘要、桌面/手机截图和旧请求乱序。测试中仅用 fetch 门控模拟网络故障或延迟，恢复后仍走原 HTTP/MSW/store。
